Aviso de Privacidade

Este aviso descreve como o Open Music Hub trata dados ao usar o site. A aplicação é um projeto independente e não é afiliada aos provedores de música.

Atualizado em: 18 de outubro de 2026. Este aviso está em revisão e não deve ser tratado como final até o canal de contato ser preenchido.

Quem é responsável

O responsável pelo projeto é seu mantenedor, cnrnival. O contato privado para dúvidas e solicitações de titulares está pendente de definição pelo mantenedor.

Aviso: o canal privado de privacidade deve ser configurado antes de divulgar o serviço para usuários finais. Não envie dados pessoais ou documentos em issues públicas do GitHub.

Dados tratados neste navegador

  • O navegador guarda localmente estatísticas de reprodução, contagens de salvamentos e itens da biblioteca para as funcionalidades do app.
  • Preferências de exibição e reprodução, o nome do perfil local e o indicador de arquivos baixados ficam no armazenamento local deste navegador. Não há conta, login ou token de acesso.
  • Arquivos escolhidos no seletor de áudio são lidos pelo player no próprio navegador e não são enviados pelo app ao servidor.

Esses dados não são sincronizados entre dispositivos. Limpe os dados do site no navegador para removê-los; a remoção desses dados também apaga preferências e biblioteca local.

Buscas e serviços de terceiros

Quando você pesquisa, os termos necessários são enviados aos catálogos chamados para obter resultados. Conforme os recursos usados, isso pode envolver Deezer, Invidious, MusicBrainz, Lyrics.ovh, TheAudioDB e Jamendo. Os perfis de artistas consultam a TheAudioDB v1. Imagens, prévias e áudio licenciados podem ser carregados diretamente dos domínios dos respectivos provedores. Cada provedor pode receber dados técnicos de conexão e aplicar seus próprios termos e avisos de privacidade.

O site é hospedado pela Vercel. Como em qualquer hospedagem web, requisições podem gerar logs técnicos, como endereço IP, data, rota solicitada e informações do navegador, sujeitos à configuração e às políticas da plataforma. Este projeto não implementa conta própria, banco de dados de perfil ou analytics de terceiros no código do app.

Finalidades e bases legais

O armazenamento local é usado para fornecer as funções que você escolhe, como biblioteca, perfil local e preferências do player. Consultas a provedores são feitas para responder às suas buscas e exibir os recursos solicitados. Registros técnicos de hospedagem servem à entrega, segurança e diagnóstico do serviço. A definição da base legal aplicável e a configuração de retenção devem ser confirmadas pelo responsável pelo deploy, conforme o contexto de uso e a legislação aplicável.

Compartilhamento e transferências

As consultas são encaminhadas aos provedores acima; chamadas de API feitas pelo servidor podem ser processadas fora do Brasil. A hospedagem e os provedores podem operar em outras jurisdições. Consulte os avisos e termos de cada serviço antes de usar o aplicativo.

Seus direitos

Nos termos da LGPD e conforme aplicável, você pode solicitar confirmação e acesso a dados pessoais, correção, anonimização, bloqueio ou eliminação, informações sobre compartilhamento e revisão de decisões automatizadas. Os dados que ficam somente no seu navegador podem ser removidos por você ao limpar os dados do site. Para solicitações ao responsável, use o canal privado de contato a ser preenchido acima.

Segurança e alterações

Credenciais de API que exigem sigilo devem ser configuradas no ambiente do servidor, nunca no JavaScript público. O app limita o uso de dados pessoais ao necessário para suas funções, mas nenhum serviço conectado à Internet pode prometer segurança absoluta. Este aviso deve ser atualizado se mudarem provedores, finalidades, retenção ou tecnologias.
